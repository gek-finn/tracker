# Task Tracker — описание для портфолио

## Кратко

Веб-приложение для управления задачами команды: список задач с поиском и
фильтрами, канбан-доска с Drag & Drop, планирование на день и неделю,
повторяющиеся задачи с автосозданием экземпляров, дашборд с отчётами по
исполнителям и проектам, экспорт в CSV и Excel с настройкой печати,
резервное копирование через SQLite Backup API.

## Стек

Python 3.10+ · Flask 3 · SQLite · vanilla JS · openpyxl · gunicorn.
Без ORM и фронтенд-фреймворков — SQL и интерфейс написаны вручную.

## Ключевые инженерные решения

- **Целостность данных**: параметризованные запросы, защита от повторной
  отправки форм (одноразовые токены в сессии), уникальный индекс и
  транзакции `BEGIN IMMEDIATE` для генерации повторяющихся задач —
  дубли исключены на уровне БД.
- **Календарная логика**: правила повторений с учётом коротких месяцев и
  високосных лет, «догоняющая» генерация после простоя с лимитом.
- **Отчёты**: единое серверное правило просрочки, фильтры по периодам,
  агрегация по исполнителям и проектам, ссылки-фильтры между разделами.
- **Экспорт**: CSV (UTF-8 BOM, экранирование, защита от CSV-инъекций) и
  Excel (стили, автофильтр, настоящие даты, подготовка к печати A4
  альбомно с повтором шапки).
- **Production-готовность**: конфигурация через переменные окружения,
  gunicorn, healthcheck `/healthz`, безопасные cookie за HTTPS-прокси,
  демо-режим «просмотр публичен, изменение — по паролю администратора».
- **Качество**: 137 автоматических тестов (unittest) на временных базах —
  CRUD, фильтры, повторения, отчёты, экспорт, бэкапы, безопасность.
- **Безопасность данных**: резервное копирование SQLite Backup API,
  проверка целостности копий, восстановление со страховочной копией.

## Запустить

Локально (Windows): двойной щелчок по `запуск.bat`.
Онлайн: развёртывание на Railway из GitHub (инструкция в репозитории).
Тесты: `python -m unittest discover`.
